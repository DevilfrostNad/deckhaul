# DeckHaul

Менеджер модов Euro Truck Simulator 2 и American Truck Simulator для Steam Deck. Проверяет, что моды установлены правильно, расставляет их в нужном порядке, записывает порядок в профиль игры и следит за обновлениями модов и самой игры.

Работает на SteamOS без установки пакетов: нужен только Python 3, который в системе уже есть. Интерфейс открывается в браузере, рассчитан на экран 1280 × 800, сенсор и кнопки Steam Deck.

## Установка

1. Переключите Steam Deck в режим рабочего стола.
2. Скопируйте папку `deckhaul` на Steam Deck, например в «Загрузки».
3. Откройте в этой папке Konsole и выполните:

```bash
./install.sh --add-to-steam
```

DeckHaul появится в меню приложений и в библиотеке Steam, откуда его можно запускать в игровом режиме. Если в системе есть Chrome, Chromium, Edge или Brave из Discover, интерфейс откроется отдельным окном без адресной строки.

Удалить: папки `~/.local/share/deckhaul-app`, `~/.local/share/deckhaul` и файлы `~/.local/bin/deckhaul`, `~/.local/share/applications/deckhaul.desktop`.

## Что проверяется

| Проблема | Что видно в DeckHaul |
| --- | --- |
| Включённого мода нет на диске | ошибка и кнопка «Убрать из списка», для Workshop — ссылка на страницу мода |
| Мод не рассчитан на текущую версию игры | ошибка по полю `compatible_versions` из `manifest.sii` |
| Повреждённый архив | ошибка: файл не открывается или не сходится контрольная сумма внутри ZIP |
| В архиве лежат другие моды (`.zip` с `.scs` внутри) | ошибка и подсказка распаковать |
| Мод упакован с лишней папкой | ошибка: игра не увидит `manifest.sii` |
| В папке `mod` лежат `.rar`, `.7z` | предупреждение: игра их не читает |
| Моды лежат в папке Proton, а игра запускается в Linux-версии, или наоборот | предупреждение с путями обеих папок |
| Один мод включён в двух копиях | ошибка, перечислены версии |
| Мод стоит не в своей группе или нарушает правило порядка | предупреждение и кнопка «Упорядочить» |
| Моды заменяют файлы друг друга | заметка; если мод перекрыт целиком, предупреждение. Кнопка «Какие файлы» показывает список |
| Steam не скачал обновление мода из Workshop | предупреждение по данным `appworkshop_227300.acf` |
| Мод удалён из Workshop или Steam не видит его обновление | после кнопки «Проверить обновления в Workshop» на вкладке «Изменения» |
| Ошибки в `game.log.txt` после последнего запуска | первые строки ошибок |

На вкладке «Изменения» DeckHaul показывает, что поменялось с прошлой проверки: новые и удалённые моды, смену версии мода, изменённые файлы с прежним номером версии и обновление самой игры.

## Порядок модов

Мод выше в списке главнее: его файлы заменяют файлы модов ниже. «Упорядочить» сначала раскладывает моды по группам сверху вниз:

закреплённые сверху → графика и погода → звук → физика → интерфейс и прочее → тюнинг и салоны → трафик → грузы → покраски → прицепы → грузовики → карты.

Потом применяются правила из `deckhaul/rules.json` и ваши собственные. Внутри группы сохраняется ваш порядок, поэтому ручные правки не теряются при повторной сортировке. Группу любого мода можно поменять вручную, и можно задать правило «этот мод всегда выше того».

Встроенные правила — это советы сообщества, например из гайда ProMods: фикс вылета при масштабировании карты ставится в самый верх, файл определений ProMods — выше остальных частей. Если правило вам мешает, его можно поправить в `rules.json`.

## Безопасность профиля

- Перед каждым сохранением и восстановлением DeckHaul копирует `profile.sii` в `~/.local/share/deckhaul/backups`. Любую копию можно вернуть на вкладке «Копии профиля».
- Если игра запущена, сохранить порядок нельзя: при выходе игра перезапишет профиль.
- Меняется только список `active_mods`, остальной файл остаётся байт в байт. Зашифрованный профиль сохраняется текстом, игра читает такой формат.
- Перед записью новый файл читается обратно и сверяется с тем, что должно получиться.

## Управление на Steam Deck

| Кнопка | Действие |
| --- | --- |
| Крестовина | переход между элементами, в списке порядка — между модами |
| A | нажать |
| X | взять мод и двигать его крестовиной, ещё раз X — отпустить |
| B | отменить перенос, закрыть окно |
| Y | упорядочить |
| L1 / R1 | переключить вкладку |
| Start | сохранить в профиль |

Мышью и пальцем мод переносится кнопками ▲ ▼, мышью — ещё и перетаскиванием.

## Командная строка

```bash
deckhaul check
```

```bash
deckhaul sort --apply
```

Остальные команды: `deckhaul profiles`, `deckhaul backups`, `deckhaul restore ИМЯ`. Параметр `--game ats` переключает на American Truck Simulator, `--data-dir` задаёт папку игры, если она не нашлась сама.

## Как это устроено

Изучены Easy SCSModManager (открытый менеджер на Python для Linux и Windows), формат архивов из библиотеки TruckLib.HashFs, гайды по порядку модов ProMods и форумов SCS. DeckHaul написан с нуля, чужой код не копировался.

- **Где лежат файлы.** Linux-версия игры хранит профили и моды в `~/.local/share/Euro Truck Simulator 2`, версия через Proton — в `steamapps/compatdata/227300/pfx/.../Documents/Euro Truck Simulator 2`. Какая папка рабочая, DeckHaul определяет по самому свежему `game.log.txt`. Библиотеки Steam, в том числе на карте памяти, берутся из `libraryfolders.vdf`.
- **Архивы `.scs`.** Поддерживаются ZIP, HashFS v1 (игра до 1.49) и HashFS v2 (1.50 и новее), а также моды-папки. Пути в HashFS хранятся как CityHash64, поэтому пересечения файлов ищутся даже у модов, автор которых скрыл список файлов.
- **Профиль.** `profile.sii` обычно зашифрован (AES-256-CBC и zlib, ключ общеизвестен). AES написан на чистом Python, чтобы не ставить пакеты в систему с защищённым от записи разделом.
- **Workshop.** Если у мода несколько версий, `versions.sii` указывает, какую папку загружать для текущей версии игры. DeckHaul выбирает её так же, как игра.

```
deckhaul/
  archive.py   ZIP, HashFS v1/v2, папки
  cityhash.py  хеш путей HashFS
  aes.py       расшифровка профиля
  sii.py       разбор SII, чтение и запись active_mods
  paths.py     поиск Steam, игры, Workshop, Proton
  mods.py      сканирование модов и кеш
  checks.py    все проверки
  order.py     группы, правила, автосортировка
  history.py   журнал изменений
  profiles.py  профили и резервные копии
  core.py      общий сервис для интерфейса и командной строки
  server.py    локальный веб-сервер, только 127.0.0.1
  web/         интерфейс
tests/         тесты и генератор тестовой «копии» Steam Deck
```

Тесты:

```bash
python3 -m unittest discover -s tests
```

При первом запуске тесты скачивают образец архива HashFS v2 из [TruckLib.HashFs](https://github.com/sk-zk/TruckLib.HashFs) (лицензия GPL-2.0) в `tests/data`. В репозиторий он не входит. Без сети этот тест пропускается.

## Ограничения

- Не проверено на настоящем Steam Deck с реальными модами: всё проверялось на тестовых данных, которые повторяют структуру папок SteamOS, и на образцах архивов HashFS v2 из TruckLib.
- Если профиль сохранён в двоичном формате (BSII), DeckHaul прочитает список модов приблизительно и не даст записать порядок. Easy SCSModManager тоже работает только с текстовыми профилями, поэтому, скорее всего, двоичные встречаются редко, но проверить это без настоящих профилей нельзя.
- Совместимость проверяется только для модов, где автор указал `compatible_versions`. У мода без этого поля версия считается неизвестной.
- Встроенных правил порядка немного. Порядок для сборок карт (ProMods с RusMap и другими) лучше брать из гайда автора сборки и задавать своими правилами.
